# Aurora Bank — итоговый проект №1

Учебный многостраничный сайт финансовой организации.

## Страницы
index.html — главная; products.html — продукты; about.html — о банке; support.html — поддержка; contacts.html — контакты.

## Технологии
HTML5, CSS3, JavaScript, Flexbox, CSS Grid, media queries, CSS-анимации, псевдоклассы, SEO meta tags, JSON-LD.

## Запуск
Откройте папку в VS Code и запустите index.html через Live Server.

## Важно
Aurora Bank — вымышленная организация. Все продукты, контакты и цифры являются демонстрационными.

После размещения сайта замените https://example.com/ в canonical, robots.txt и sitemap.xml на настоящий адрес.


## SEO и аналитика

В HTML добавлены SEO-метатеги, Open Graph, canonical, robots directives и hreflang. Также добавлены заготовки Google Analytics 4 и Яндекс Метрики. Перед публикацией замените:
- `G-XXXXXXXXXX` на Measurement ID Google Analytics 4;
- `00000000` на ID счётчика Яндекс Метрики;
- `https://example.com/` на реальный адрес сайта в canonical, sitemap.xml, robots.txt и Open Graph.

Не используйте тестовые ID в качестве реальной аналитики.
